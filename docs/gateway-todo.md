## G1：最小可验证的安全管道（首个实现里程碑）

- [ ] 建立独立 gateway 模块、存储迁移及配置校验；默认仅本机监听。
- [ ] 实现网关 Key 校验、组织/用户/Channel 授权、撤销和过期。
- [ ] 实现固定上游、模型白名单及最小 `/v1/models`。
- [x] 实现非流式文本 `/v1/chat/completions`；严格校验支持字段。
- [x] 实现请求 ALLOW/REDACT/BLOCK、实际出站内容复检与回答策略（固定预设；动态策略归 G2）。
- [ ] 设置检测失败阻断、请求限制、超时、SSRF 防护和最小审计。
- [x] 编写记录型测试上游与虚构测试数据。

完成条件：授权请求成功往返；私钥、无权限、检测故障三类场景上游请求数为零；脱敏场景实际出站体无已标注原值；回答违规不返回原始回答；不支持输入明确拒绝。独立运行说明可复现。

## G2：可操作的管理后台

- [ ] 独立管理员登录、角色鉴权；浏览器会话具备 CSRF 等必要保护。
- [ ] 概览、用户/Key、上游、Channel、策略、测试、审计页面。
- [ ] Key 单次展示、撤销；上游密钥不可读回，安全存储与轮换。
- [ ] 预设规则及虚构测试编辑；能清楚解释命中原因和处理动作。
- [ ] 不可变策略版本、依赖快照、差异、测试绑定、显式启用/回滚。
- [ ] 按 Key 导出 Base URL、模型和接入步骤，区分 MCP 与模型配置。

完成条件：管理员从空配置走完“用户→上游→测试策略→Channel→启用→发 Key→测试→审计→撤销”；操作员无法发布；审计员无法编辑；未启用草稿不改变请求行为；跨租户访问全拒绝。

## G3：PrivacyGuard 与真实客户端接入

- [ ] 以显式配置将 PrivacyGuard 受控模型请求接到网关，避免重复路由和调用循环。
- [ ] 固定任务 `secure_ask` 保持原引用与回答质量校验；现有测试不退化。
- [ ] 用虚构材料接真实上游，分别记录安全检查与回答质量结果。
- [ ] 核实目标版本 WorkBuddy/Codex 的模型配置及协议；需要 Responses、tools 或 streaming 时另建实现任务，未完成则明确不支持。
- [ ] 更新 README、配置说明、FAQ，给出脱敏成功、策略阻断、检测故障和协议不支持的用户提示。

完成条件：只对实际验证的客户端/版本宣称兼容；有请求记录证明流量经过网关；不声称 MCP 自动接管订阅流量；日志无原文/Key。

## G4：Round Trip 与受控本地回填

- [ ] 设计独立 Vault、密钥管理、项目/会话隔离、TTL、撤销与并发分配。
- [ ] 实现登记占位符、用户输入冲突处理及同案跨文件一致性。
- [ ] 校验接收端权限，默认仅向本地受控展示回填；MCP 默认保持假名。
- [ ] 检查未知/伪造占位符、跨用户/跨案件/过期映射及多轮重新脱敏。
- [ ] 建立禁止回填类别，证明 API Key/私钥不会被恢复。

完成条件：授权本地接收端正确还原，外部上游从未接收映射或原值；隔离、失效、伪造及服务失败测试全部通过。不以同名自动合并身份。

## 验收矩阵

| 编号 | 情景 | 必须观察到的结果 |
|---|---|---|
| A01 | 未授权/过期/撤销 Key、跨组织请求 | 拒绝；测试上游请求数为零 |
| A02 | Channel 或模型越权 | 拒绝；不泄露其他租户模型或配置 |
| A03 | 请求含虚构手机号/邮箱 | 只发送策略批准的假名内容，统计准确 |
| A04 | 请求含私钥、强制 BLOCK 与 ALLOW 同时命中 | BLOCK 优先，上游请求数为零 |
| A05 | Presidio/HaS 超时或返回无效数据 | 阻断，无原文回退 |
| A06 | 上游回答含受限原值 | 阻断或脱敏复检；客户端未先收到原始片段 |
| A07 | stream/tools/image/未知字段 | 首版明确拒绝，不能透传 |
| A08 | 草稿修改、测试后再改、启用与回滚 | 草稿不生效；旧测试失效；请求版本一致 |
| A09 | 恶意 URL、重定向、超大输入、限流 | 明确拒绝或超时；不访问未授权目标 |
| A10 | 管理员/操作员/审计员与跨租户操作 | 服务端校验通过或拒绝，不能仅靠隐藏按钮 |
| A11 | 日志、错误、审计存储异常 | 无原文/凭据；审计不可用时阻断新请求 |
| A12 | 授权及未授权的回填（G4） | 只向授权接收端恢复登记映射；其他路径不泄露 |

每个里程碑 PR 需记录：实现范围、关联任务、测试命令与结果、未支持协议、已知限制及回滚方式。只有有验收证据的条目才能勾选；文档存在不等于实现通过。此次不承诺未经实测的工期、吞吐或零漏检。
