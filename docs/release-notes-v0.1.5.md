# v0.1.5

## 识别与安全策略

- Apple Silicon MLX NER 统一使用保守提示模式，过滤通用合同和业务词，保留有上下文的专有项目名。
- 语义实体按 2400 字符窗口处理，长文档尾部和重复实体继续覆盖测试。
- 手机、邮箱、证件号、地址等高风险类型自动进入脱敏；项目、机构、法院、律所等语义类型显示为“需要人工确认”。
- 低置信度语义实体不能直接生成安全 PDF/DOCX，必须人工确认，否则 fail-closed。

## 桌面端

- 复核面板区分“自动脱敏”和“需要人工确认”。
- 自动脱敏类型默认确认，语义实体保持待复核状态。
- 复核统计只记录数量，不记录原始实体值。

## 凭证和日志

- 安全引用默认有效期从 1 小时调整为 15 分钟，可用 `PRIVACYGUARD_REFERENCE_TTL` 覆盖。
- 引用调试日志只保留前后少量字符；客户端应优先使用 MCP `structuredContent`。
- 文件名在本地识别日志中使用摘要标识，不记录原始文件名。

## 已知限制

- MLX 仍需要 Apple Silicon 和已安装的 `mlx-lm`；其他平台可使用规则模式。
- 识别结果不能证明零漏检，安全副本仍需人工抽查。
