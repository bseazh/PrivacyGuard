运行概览

策略草稿 → 测试 → 发布 → 显式绑定通道 → Trace 验证 → 按需回滚。私钥标记、不确定实体及复检残留始终阻断。回填、多组织部署尚未提供。

1. 用户管理

策略编辑、测试与发布

匹配表达式负责找到候选内容；<PHONE_001> 是替换后的占位符。表达式由代码维护，下面可编辑请求/回答动作。不提供敏感原值 ALLOW，姓名、机构仍需语义识别。

1. 编辑草稿

每个本机组织一份共享草稿。保存后旧测试失效；刷新会丢弃尚未保存的编辑。识别类型没有单独配置时使用默认动作。

2. 测试后发布

固定虚构用例执行与线上相同的动作引擎，不调用模型；通过不代表真实材料召回率。发布仅创建不可变版本，不自动启用。

3. 查看差异、显式启用 / 回滚

选择历史版本并启用即为回滚；正在处理的请求继续使用进入时的版本，撤销授权仍即时复核。
