PrivacyGuard

本地识别 + Presidio + RedactionEverything + LiteLLM

macOS Apple Silicon 一句话安装

适用于 M1、M2、M3、M4 系列 Mac。不提供 DMG，不安装捆绑应用。打开“终端”，复制下面整行并回车：

curl -fsSL https://privacyguard.snorlaxden.fun/install.sh | bash

脚本自动预检、断点下载、SHA-256 校验、安装、启动并执行真实端到端验收。

安装内容

默认目录：~/Documents/PrivacyGuard。下载约 4GB，包括源码、Qwen3、HaS 和 PaddleOCR 独立组件。LiteLLM 只保护 PrivacyGuard 的 privacy_secure_ask，不会接管 Codex 原生流量。

Windows 与 Intel Mac 尚未完成同等能力验收，当前不提供误导性入口。
